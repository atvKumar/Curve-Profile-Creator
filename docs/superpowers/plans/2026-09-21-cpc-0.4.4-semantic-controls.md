# CPC 0.4.4 Semantic Controls Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add semantic component Rotation/Size and committed-profile Rotation/Uniform Scale to the viewport HUD, expose component Rotation/Size gestures in the panel, and give every pointer-driven Rotation/Size path the same Shift/Ctrl behavior.

**Architecture:** Put modifier calculations and exact-value parsing in a Blender-independent module. Extend the existing semantic-field adapter to classify component and profile targets, then keep the overlay and modal operator as thin consumers of those tested semantics. Panel buttons and R/S keymaps invoke the same component operators, so component dimensions and canonical profile placement remain the only authoritative state.

**Tech Stack:** Python 3, Blender 4.3+ Python API, `bpy`, `mathutils`, BLF/GPU viewport drawing, `unittest`.

**Spec:** `docs/superpowers/specs/2026-09-21-cpc-0.4.4-release-closeout-design.md`

## Global Constraints

- Keep recipe schema 11+, transform schema 1, and `.cpcprofile` format v1.
- Do not add a persistent component Scale/Size property; construction dimensions remain authoritative.
- Preserve lazy viewport-overlay handler creation during extension registration and file loading.
- Keep `cpc.viewport_dimension_edit` and its E key binding stable.
- Component Size must regenerate dimensions and finish with Object Scale `1,1,1`.
- Profile Rotation/Uniform Scale must write `cpc_profile_placement_json` through the canonical setter.
- Shift is one-tenth pointer sensitivity; Ctrl snaps; Shift+Ctrl uses one-tenth snap increments; typed values are exact.
- Preserve Edit Anchor, Maintain Connected, packed-controller regeneration, Edit Active Profile, Recommit, save/reload, and Sweep behavior.

## Review Focus

- Modifier keys toggled halfway through a gesture must resolve from the unsnapped baseline, not accumulate rounded deltas; Task 1 tests the same raw input under every modifier state.
- Selecting a child of a packed component must resize controller length parameters and normalize every instance part; Task 2 retains and tests controller ownership while Task 4 uses the existing packed resize state.
- A committed profile with non-uniform or non-positive raw Object Scale must reject overlay scaling without partial mutation; Task 3 adds state-resolution tests and Task 4 verifies the rejection path.
- Escape/right-click after live component or profile scrubbing must restore the complete captured state; Task 4 adds cancellation tests around the extracted baseline/apply helpers.
- Enabling the feature must not install draw handlers during registration/load; Task 5 includes a source lifecycle assertion and the #7 Blender matrix exercises lazy activation.

```python
"""Blender-independent math for CPC semantic Rotation and Size gestures."""

from __future__ import annotations

import math


FINE_FACTOR = 0.1
SIZE_SNAP = 0.1
MIN_FACTOR = 0.001


def _finite(value, label):
    try:
        result = float(value)
    except Exception as exc:
        raise ValueError(f"{label} must be numeric") from exc
    if not math.isfinite(result):
        raise ValueError(f"{label} must be finite")
    return result


def rotation_delta(raw_delta, *, shift=False, ctrl=False, snap_radians=0.0):
    value = _finite(raw_delta, "Rotation delta")
    fine = FINE_FACTOR if shift else 1.0
    value *= fine
    if ctrl:
        step = _finite(snap_radians, "Rotation snap") * fine
        if step <= 0.0:
            raise ValueError("Rotation snap must be greater than zero")
        value = round(value / step) * step
    return value


def resize_factor(raw_factor, *, shift=False, ctrl=False):
    raw = _finite(raw_factor, "Resize factor")
    fine = FINE_FACTOR if shift else 1.0
    value = 1.0 + (raw - 1.0) * fine
    if ctrl:
        step = SIZE_SNAP * fine
        value = round(value / step) * step
    return max(value, MIN_FACTOR)


def parse_angle_degrees(text):
    return math.radians(_finite(str(text).strip(), "Rotation"))


def parse_positive_factor(text):
    value = _finite(str(text).strip(), "Size")
    if value <= 0.0:
        raise ValueError("Size must be greater than zero")
    return value
```

```python
@dataclass(frozen=True)
class SemanticField:
    field_id: str
    label: str
    owner: object | None
    prop_name: str
    editable: bool = True
    kind: str = "LENGTH"
    value_override: float | None = None

    @property
    def value(self) -> float:
        if self.value_override is not None:
            return float(self.value_override)
        return float(getattr(self.owner, self.prop_name))


def target_kind(obj):
    if not obj or getattr(obj, "type", "") != "CURVE" or obj.get("cpc_preview"):
        return ""
    if obj.get("cpc_part") and obj.get("cpc_parametric"):
        return "COMPONENT"
    if obj.get("cpc_profile") and not obj.get("cpc_part"):
        return "PROFILE"
    return ""
```

```python
def resolve_profile_semantic_field(state, field_id, value) -> dict:
    value = _finite_float(value, float("nan"))
    if not math.isfinite(value):
        raise ProfileTransformError("Profile transform value must be finite")
    if field_id == "profile_rotation":
        return resolve_profile_placement(state, rotation=value)
    if field_id == "profile_uniform_scale":
        if value <= 0.0:
            raise ProfileTransformError("Uniform Scale must be greater than zero")
        return resolve_profile_placement(state, uniform_scale=value)
    raise ProfileTransformError(f"Unsupported profile semantic field: {field_id}")
```
