# CPC 0.4.4 Reconnect Touching Endpoints Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an explicit operator that rebuilds CPC endpoint junction IDs for physically coincident construction endpoints without moving geometry.

**Architecture:** A pure union-find planner clusters immutable endpoint records within `merge_tolerance` and chooses deterministic surviving junction IDs. `junctions.py` adapts Blender objects to/from that plan, while `operators.py` resolves the active construction scope and presents reports. Reconnection writes only endpoint/host metadata; it never writes matrices, curve coordinates, handles, or semantic dimensions.

**Tech Stack:** Python 3, Blender 4.3+ Python API, `bpy`, `mathutils.Vector`, `unittest`.

**Spec:** `docs/superpowers/specs/2026-09-21-cpc-0.4.4-release-closeout-design.md`

**Execution order:** Run after the semantic-controls plan and before the release-validation plan.

## Global Constraints

- Reconnection is explicit and never runs automatically from proximity or depsgraph callbacks.
- Use the configured CPC `merge_tolerance` in world-space distance.
- Prefer the active build/Edit Active Profile session; otherwise use selected eligible CPC parts.
- Do not move or regenerate geometry.
- Preserve one existing junction ID when a touching cluster already has one.
- Do not mutate non-touching endpoints or parts outside the resolved scope.
- Affected hosted attachments are cleared because endpoint-to-endpoint reconnection supersedes them.
- Maintain Connected must traverse the rebuilt chain using existing connectivity code.

## Review Focus

- A point exactly at `merge_tolerance` must reconnect while one just outside must remain unchanged; Task 1 tests both boundaries.
- Transitive coincidence (A near B, B near C) must produce one cluster even when A-to-C is slightly larger than the tolerance; Task 1 tests union-find transitivity.
- Coincident start/end points belonging only to one object must not create a self-junction; Task 1 tests the distinct-object rule.
- An endpoint outside a touching cluster that happens to reuse a stale losing ID must remain byte-for-byte unchanged; Task 2 tests local assignment rather than global ID replacement.
- Reconnecting an endpoint with hosted metadata must clear only that endpoint's hosted record and leave all endpoint coordinates unchanged; Task 2 snapshots both metadata and geometry.

## File Structure

- Create `endpoint_reconnect.py`: immutable record/cluster types and pure deterministic clustering.
- Create `tests/test_endpoint_reconnect.py`: distance, transitivity, ordering, and ID-selection tests.
- Modify `junctions.py`: object snapshot/application adapter and reconnect statistics.
- Create `tests/test_junction_reconnect.py`: metadata-only integration tests with lightweight Blender stubs.
- Modify `operators.py`: candidate-scope resolution, operator, reports, and registration.
- Modify `ui.py`: explicit Reconnect Touching Endpoints control.
- Create `tests/test_reconnect_ui_contract.py`: operator registration and UI wiring contract.

- [ ] **Step 3: Implement deterministic union-find clustering**

Sort records by `(sequence, object_key, endpoint_index)`. Union two record indices when squared Euclidean distance is `<= tolerance * tolerance`. For each root, retain only groups with at least two members and at least two distinct `object_key` values. Preserve unique non-empty IDs in member order; the first is `keep_id`, the remainder are `merged_ids`, and no IDs means `needs_new_id=True`.

```python
def _distance_sq(left, right):
    return sum((float(a) - float(b)) ** 2 for a, b in zip(left, right))


def plan_reconnections(records, tolerance):
    tolerance = float(tolerance)
    if not math.isfinite(tolerance) or tolerance <= 0.0:
        raise ValueError("Reconnect tolerance must be greater than zero")
    ordered = tuple(sorted(records, key=lambda item: (
        int(item.sequence), str(item.object_key), int(item.endpoint_index)
    )))
    parent = list(range(len(ordered)))

    def find(index):
        while parent[index] != index:
            parent[index] = parent[parent[index]]
            index = parent[index]
        return index

    def union(left, right):
        left_root, right_root = find(left), find(right)
        if left_root != right_root:
            parent[right_root] = left_root

    limit = tolerance * tolerance
    for left in range(len(ordered)):
        for right in range(left + 1, len(ordered)):
            if _distance_sq(ordered[left].position, ordered[right].position) <= limit:
                union(left, right)

    grouped = {}
    for index, item in enumerate(ordered):
        grouped.setdefault(find(index), []).append(item)

    result = []
    for members in grouped.values():
        if len(members) < 2 or len({item.object_key for item in members}) < 2:
            continue
        ids = tuple(dict.fromkeys(item.junction_id for item in members if item.junction_id))
        result.append(ReconnectCluster(
            members=tuple(members),
            keep_id=ids[0] if ids else "",
            merged_ids=ids[1:],
            needs_new_id=not ids,
        ))
    return tuple(result)
```

```python
def reconnect_touching_endpoints(objects, tolerance):
    unique = {}
    for obj in objects or ():
        unique.setdefault(_reconnect_object_key(obj), obj)
    objects = list(unique.values())
    by_key = {_reconnect_object_key(obj): obj for obj in objects}
    records = _endpoint_records(objects)
    groups = endpoint_reconnect.plan_reconnections(records, tolerance)
    new_count = 0
    merged_count = 0
    endpoint_count = 0
    for group in groups:
        junction_id = group.keep_id
        if not junction_id:
            junction_id = new_id()
            new_count += 1
        merged_count += len(group.merged_ids)
        for member in group.members:
            obj = by_key[member.object_key]
            clear_hosted_attachment(obj, member.endpoint_index)
            set_endpoint_id(obj, member.endpoint_index, junction_id)
            endpoint_count += 1
    return ReconnectStats(len(groups), endpoint_count, new_count, merged_count)
```

def reconnect_eligible(obj):
    return bool(
        obj
        and getattr(obj, "type", "") == "CURVE"
        and obj.get("cpc_part")
        and obj.get("cpc_parametric")
        and not obj.get("cpc_preview")
    )


def choose_reconnect_candidates(active_parts, selected_parts):
    active = [obj for obj in active_parts if reconnect_eligible(obj)]
    if active:
        return active
    return [obj for obj in selected_parts if reconnect_eligible(obj)]
