### 0.4.7 creation rule

```text
selected CPC part
→ endpoint opposite Edit Anchor
→ derive outward tangent
→ create P0 at endpoint
→ create P1 along tangent
→ explicit collinear handle geometry
→ set both points to ALIGNED
→ hand editing to Blender
```

`ALIGNED` is a creation default only. If the user later changes a point to Free, Vector, Auto or another supported Blender handle type, Commit/Recommit preserves the resulting native state rather than forcing ALIGNED again.

### Graph safety

**Add Custom Bézier** does not silently branch an already-connected continuation endpoint. If that endpoint already owns a downstream semantic connection, creation is refused so the user can explicitly change Edit Anchor or remove/restructure the existing connection.
